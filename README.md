# 最良近似多項式の導出とアルゴリズム

本リポジトリは、著者（**imohiyoko**）による卒業研究「最良近似多項式の導出とアルゴリズム」の
成果物（LaTeX 原稿・実装コード・実験結果）を公開用にまとめたものです。

Remez（ルメ）アルゴリズムと Brent 法を用いて、ルンゲ関数
$f(x) = 1/(1+25x^2)$ に対する一様ノルム最小の最良近似多項式を数値的に導出し、
グリッド極値点探索を用いた従来手法と比較して、機械イプシロン程度の精度で
チェビシェフの交替定理を満たす解が得られることを示しています。
