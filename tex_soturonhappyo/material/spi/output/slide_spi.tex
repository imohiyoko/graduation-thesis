    \begin{column}{0.4\textwidth}
      \begin{itemize}
        \item \textcolor{blue}{\textbf{青丸}}: 補間に使用する3点
        \item \textcolor{green}{\textbf{緑破線}}: 3点を通る近似放物線
        \item \textcolor{red}{\textbf{赤丸}}: 放物線の頂点 
      \end{itemize}
      \vspace{1em}
      \small
      頂点付近では極めて高速に収束するが、初期値が悪いと放物線が反転して遠くへ飛んだり、更新が停滞したりするリスクがある。
