\begin{frame}{収束性能の考察}
  \begin{itemize}
    \item 黄金分割法は対数軸で直線的に減衰（線形収束）
    \item Brent法は放物線補間が効き始めると急激に減衰（超線形収束）
    \vspace{1em}
    \item \textbf{結論}:
    \begin{itemize}
      \item Brent法は黄金分割法と比べ、イテレーション数で約 2.6倍高速に収束
      \item 計算時間では約 3.21倍高速に収束
      \item 放物線補間が効率的に機能していることを示す
    \end{itemize}
  \end{itemize}
\end{frame}
